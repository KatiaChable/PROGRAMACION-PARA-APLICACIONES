## Parcial 1. Manejo de excepciones

Se presenta una implementación en java de todo el diagrama UML revisado durante el primer parcial.

Este programa tiene 1 clase padre y 3 subclases

### GeometricObject
Se trata de la clase padre del programa de la cual todos van a heredar los atributos y constructores.

### Circle
Clase para crear un cirulo con el atributo radius.

### Rectangle
Clase para crear un rectángulo con el atributo width y height ambos doubles.

### Triangle
Clase para crear un triángulo con los atributos side1, side2 y side3.

## IllegalTriangleException
Clase creada como excepción por si los lados del triángulo son invalidos.
